# Pokédex TypeScript Lite

## Sobre o projeto

Aplicação back-end em Node.js com TypeScript que consulta a PokeAPI, trata erros, mapeia dados e mantém um catálogo local em memória.

## Tecnologias utilizadas

- Node.js
- TypeScript
- TSX (execução em desenvolvimento)
- PokeAPI (pública, sem autenticação)

## Pré-requisitos

- Node.js (versão 18 ou superior – necessário para `fetch` nativo)
- npm
- Git
